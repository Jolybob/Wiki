# Pathfinder 2e Wiki

A minimal, static template for a Pathfinder 2e wiki.

## Status

The wiki is intentionally empty. The current site provides:

- Responsive wiki shell
- Category navigation
- Search UI placeholder
- Empty-state presentation
- No framework or build step

## Structure

- `index.html` — page structure
- `styles.css` — theme and responsive layout
- `script.js` — small client-side interactions

## Local preview

Serve the repository with any static HTTP server, or open `index.html` directly in a browser.

## GitHub Pages

This is ready to deploy as a GitHub Pages static site from the `main` branch.
